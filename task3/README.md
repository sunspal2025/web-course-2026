# Todo на чистом JavaScript

Открыть `index.html` или `/task3/` на Pages. Добавление кнопкой и Enter, удаление, отметка, три фильтра и общие счётчики.

Состояние — массив объектов; render строит DOM, filter выбирает записи, map обновляет задачу. Ввод вставляется через textContent. После перезагрузки задачи исчезают, как требует задание.

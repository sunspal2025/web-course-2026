# Zen-Money: CRUD

Требуется Node.js 22+. Из корня репозитория: `npm ci`. В `task8` затем `npm run server` (API :3001). В другом терминале `npm start`, открыть http://localhost:8080/task8/.

Операции и категории хранятся только в db.json на сервере. api.js отвечает за HTTP, ui.js за DOM, main.js за состояние и события. Есть GET/POST/PATCH/DELETE, сводка и обработка недоступного сервера. На Pages интерфейс виден, но для CRUD нужен локальный API. Перед проверкой можно сохранить копию db.json: изменения записываются на диск.

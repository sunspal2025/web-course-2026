# Simon

Открыть `index.html` или `/task5/`. Повторять последовательность кнопок; звук включается отдельно.

Состояние phase блокирует ввод во время показа. Все timeout хранятся в Set и отменяются при перезапуске/уходе со страницы: старые последовательности не накладываются на новые. Звук через AudioContext, его сбой не останавливает игру.

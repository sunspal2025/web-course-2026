03 / 5:00–7:00

Вопросы, к которым стоит подготовиться

Зачем useEffect?

Чтобы синхронизировать компонент с внешним API после монтирования. Добавление операции происходит в обработчике формы, а не в effect.

Почему API в отдельном модуле?

Один модуль задаёт URL, проверяет response.ok и преобразует ошибки. Компоненты не повторяют детали HTTP.

Как защищено состояние при ошибке?

Список обновляется после успешного ответа сервера. При ошибке показывается сообщение, а введённые данные формы сохраняются.

Чем CSR отличается от SSR и SSG?

CSR загружает данные в браузере. SSR создаёт HTML на сервере при запросе. SSG создаёт HTML во время сборки; для постоянно меняющихся финансов он потребовал бы обновления.

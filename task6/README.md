# Змейка

Открыть `index.html` или `/task6/`. Стрелки меняют направление, пауза и перезапуск доступны кнопками. Canvas — 400×400, клетка — 20 px.

requestAnimationFrame накапливает прошедшее время, update делает шаг раз в 150 мс, draw только рисует. Обратный разворот и второй поворот в одном тике игнорируются. Яблоко выбирается из свободных клеток; заполнение всего поля — победа.

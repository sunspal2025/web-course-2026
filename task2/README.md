# Адаптивный лендинг «Форма»

Открыть `index.html` или [Pages](https://sunspal2025.github.io/web-course-2026/task2/). Mobile First, Grid для секций, Flexbox внутри компонентов, точки 768 и 1200 px.

Макет Figma не предоставлен: реализован собственный дизайн. Соответствие макету преподавателя требует отдельной сверки после получения ссылки. Форма — только вёрстка, отправки нет; мобильное меню работает нативно через details без JavaScript.

# Адаптивный лендинг «Форма»

Открыть `index.html` или [Pages](https://sunspal2025.github.io/web-course-2026/task2/). Mobile First, Grid для секций, Flexbox внутри компонентов, точки 768 и 1200 px.

По согласованию реализован собственный дизайн без макета Figma. Форма — только вёрстка, отправки нет; мобильное меню работает нативно через details без JavaScript.

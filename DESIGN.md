# Визуальная система практикума

Референс по запросу владельца: https://github.com/mjmirza/apple-design-system, в частности governance/apple-design-language-rule.md и catalog/02-foundations.md. Использованы принципы ясности, иерархии, спокойных поверхностей и сдержанной прозрачности; CSS и компоненты написаны для этого проекта. Файлы шрифтов, SF Symbols и UI-киты Apple не используются.

Единый источник токенов — design-system.css: фон, текст, поверхности, контрастные статусы, синий акцент, состояния ввода и focus-visible. Шрифт — системный стек без внешних загрузок. Полупрозрачность ограничена навигацией, у карточек почти непрозрачный фон для читаемости.

Система поддерживает предпочтение тёмной темы, явную тему финансового приложения и prefers-reduced-motion. Исключение — task1: самостоятельный style.css без медиазапросов и без Grid сохраняет ограничения первой лабораторной, используя ту же светлую палитру. В task2 сохранены Mobile First и min-width 768/1200; игровая и серверная логика сохранена.

Портрет в assets/vyacheslav-paltsev.png предоставлен владельцем для публикации. Сведения профиля: Java-разработчик, текущая должность Business Analyst в GP Solutions. Новые технологии, сроки работы и биографические факты не добавлялись.

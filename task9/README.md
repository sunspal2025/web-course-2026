# Zen-Money: настройки и фильтры

Продолжение task8 без копирования модулей. Из `task8` запустить `npm ci`, `npm run server`, в другом терминале `npm start`; открыть http://localhost:8080/task9/.

Добавлены фильтры по типу, категории и датам, создание категорий и светлая/тёмная тема. localStorage содержит только zen-settings, операции остаются на json-server. Проверка положительной суммы, обязательных даты/категории выполняется до POST/PATCH.

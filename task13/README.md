# Zen-Money: динамический маршрут и деплой

Продолжение Next.js-проекта в `../task12`. Запуск из корня: `npm ci`, `npm run server --workspace=task8`, в другом терминале `npm run dev --workspace=task12`.

`/transaction/[id]` получает id через params и запрашивает конкретную операцию. Ошибки сервера и неизвестный id показаны пользователю. Навигация — next/link.

## CSR, SSR и SSG в этом проекте

Список, форма и статистика используют CSR: браузер обращается к локальному json-server после монтирования. SSR подошёл бы для подробностей операции, если бы API был доступен серверу Next.js: HTML с данными можно было бы вернуть сразу. SSG подходит для неизменяемой справки, но не для постоянно меняющегося баланса: статическая сборка сама не обновит финансовые данные.

## Vercel

В проекте Vercel выбрать этот репозиторий и Root Directory `task12`, Framework Preset `Next.js`. Установка зависимостей — из workspace корня по package-lock.json; стандартная сборка `npm run build`. Переменную NEXT_PUBLIC_API_URL менять только при наличии собственного опубликованного API.

Первый деплой выполнен 24.10.2026: успешная публикация подтверждена страницей Vercel и статусом Vercel в GitHub. [Проект в Vercel](https://vercel.com/slav6/web-course-2026). Публичный адрес будет добавлен после получения ссылки Visit от владельца. Даже после деплоя локальный json-server не станет публичным: полный CRUD проверяется локально. При недоступном API интерфейс показывает ошибку подключения вместо фиктивных данных.

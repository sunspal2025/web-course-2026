# Бесконечная лента

Открыть через HTTP или `/task7/` на Pages. Нужен интернет для JSONPlaceholder. Порции по 10, остановка на 100, поиск без учёта регистра с debounce 300 мс.

IntersectionObserver вызывает loadMore; флаги защищают от параллельных запросов. Ошибка не увеличивает номер страницы, повтор загружает ту же порцию. Поиск фильтрует локальный массив, не отправляет запрос на каждый символ.

Реальный API проверен: GET /posts?_page=1&_limit=10 возвращает 10 постов с id 1–10. В тестах ошибок используются подменённые ответы, чтобы сценарии не зависели от внешней сети.
